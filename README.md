# CodeChef Class Performance Tracker 🚀

A web-based platform designed to track, organize, and monitor students' coding performance on CodeChef.

## 📌 About the Project

The **CodeChef Class Performance Tracker** aims to simplify the process of monitoring students' coding activities and performance.

The project is built using Python and Flask, with database support for managing application data.

## 🛠️ Technology Stack

- **Backend:** Python, Flask
- **Database:** SQLite (Development), MySQL (Production)
- **Frontend:** Update according to the technologies used in this project
- **Platform:** CodeChef API integration (configuration)

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd CodeChef_Class_Tracker
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure environment variables

Create a `.env` file using `.env.example` as a template.

Add your own secret keys and database configuration.

**Never upload your actual `.env` file to GitHub.**

### 6. Run the application

Use the startup command corresponding to your Flask application entry point.

## 🔐 Security

- Environment variables are used for sensitive configuration.
- Database credentials should remain private.
- Secret keys and API credentials must not be committed to GitHub.
